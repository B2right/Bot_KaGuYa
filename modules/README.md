# 外挂模块

每个模块一个子目录，独立开发、独立运行。

调用契约见 [`../docs/module-contract.md`](../docs/module-contract.md)。

## 规划中

| 模块 | 职责 | 状态 |
|---|---|---|
| `gallery` | 辉夜图库（随机 / 按心情挑图） | 阶段 2 |
| `bili` | 搜视频 → 读字幕 → 返回候选 + 评论草稿 | 阶段 4 |
| `stg` | 联机邀请文案 + 启动避弹程序、播报结果 | 阶段 5 |

## 约定

- 模块**不知道**自己会被谁调用，只按契约收发 JSON。
- 模块**不发言**：返回 `summary`，怎么说是主体和人格卡的事。
- 模块可以单独运行（`node xx.mjs` / `python xx.py`），不依赖主体。
